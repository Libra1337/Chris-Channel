# Glossary: names that are never translated

The 中文 version is written by hand. It is not machine translation. The site sets
`translate="no"` and `<meta name="google" content="notranslate">`, so browser page
translation does not rewrite the English text.

Keep these names in their original form in every language.

| Kind | Names |
|---|---|
| Products and brands | LynShen, Aogiri, Lumen (companion name; 「光体」 is allowed as a description) |
| Brand marks | 林光 (the logo name; keep in Chinese in both languages) |
| Programming languages | Rust, Go, TypeScript, JavaScript, Python, Swift, Kotlin, Java, HTML, CSS, Shell, PowerShell |
| Frameworks and libraries | Astro, GSAP, Lenis, React, React Native, Expo, Expo Router, Reanimated, zustand, Svelte, SvelteKit, Tauri, Vite, Vitest, Playwright, axum, tokio, SeaORM, sqlx, Tailwind, shadcn/ui, Next.js, Fumadocs, Remotion, FFmpeg, Bun, Hono, Drizzle, zod, React Router, Spring Boot, Maven, SQLite, PostgreSQL |
| Platform features | AlarmKit, App Intents, Shizuku, Face ID, APNs, FCM, Web Push, MCP, ACP, Noise IK, Seatbelt, bubblewrap |
| Repos | Jm2api, accc-Libra, MD_reader (app name: mdread), llm-provider-kit |
